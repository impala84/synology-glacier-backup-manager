    CANCELLATION REQUESTED
    The runner is stopping the job
    Normal cancellation checks frequently and force-kills an unresponsive rclone upload after ten seconds. If the job is still shown as active after 30 seconds, paste this emergency command into the Synology terminal:
    for pid in $(ps aux | awk '/[r]clone (copy|copyto)/ {print $2} /[g]lacier-runner.py/ {print $2}'); do sudo kill -KILL "$pid"; done
    This stops the Glacier runner and active rclone copy processes. Afterwards, select Glacier Backup Manager in DSM Task Scheduler and click Run.
    
  
    LOCAL RECOVERY
    Reset the administrator account
    For security, password recovery requires access to the Synology terminal. This command preserves the existing credentials as a timestamped backup and restarts the app:
    sudo mv /volume1/docker/synology-glacier-backup-manager/data/auth.json /volume1/docker/synology-glacier-backup-manager/data/auth.json.reset-backup-$(date +%Y%m%d-%H%M%S) && sudo docker restart synology-glacier-backup-manager
    When the app returns, refresh this page and create a new administrator username and password. Backup settings and history are not affected.
